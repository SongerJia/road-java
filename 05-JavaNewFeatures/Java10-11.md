### var
什么是var
```
// var：局部变量类型推断
// 编译器根据初始化的值推断类型

// ❌ 之前：
Map<String, List<Integer>> userScores = new HashMap<>();

// ✅ var：
var userScores = new HashMap<String, List<Integer>>();
// 编译器推断：HashMap<String, List<Integer>>

// 或者直接推断完整类型：
var userScores = new HashMap<String, List<Integer>>();
var list = new ArrayList<String>();      // ArrayList<String>
var name = "张三";                        // String
var count = 10;                           // int
```
var用在什么地方？
```
// ✅ 可以用：局部变量（方法内）
public void process() {
    var list = new ArrayList<String>();   // ✅
    var user = new User("张三", 25);       // ✅
    var result = userService.findUser(1L); // ✅ 推断返回值类型
}

// ✅ 可以用：for 循环
for (var i = 0; i < 10; i++) { ... }
for (var user : userList) { ... }

// ✅ 可以用：Lambda 参数（Java 11+）
// 注意：必须显式类型 + 统一风格
BiFunction<String, String, Integer> f = (var a, var b) -> a.length() + b.length();

// ❌ 不可以用：
// ① 字段（成员变量）
// private var name = "x";  // ❌

// ② 方法参数
// public void process(var x) { }  // ❌

// ③ 方法返回值
// public var process() { }  // ❌

// ④ 没有初始化
// var x;  // ❌

// ⑤ null 初始化
// var x = null;  // ❌ 无法推断

// ⑥ Lambda 只写一个 var
// (var a, b) -> ...  // ❌ 要么全写要么全不写
```
var的本质
```
// var 是"语法糖"，编译期就确定类型
// 运行期没有 var（不存在这个类型）

// var x = 10;  编译后：int x = 10;
// var s = "a"; 编译后：String s = "a";

// 不是动态类型！Java 依然是静态类型
// 类型是编译器推断的，不是运行时决定的
```
使用规范
```
// ✅ 推荐：类型名太长/重复时用
var userMap = new HashMap<String, List<User>>();
// 类型太长，用 var 可读性更好

// ✅ 推荐：类型可以从右侧明显看出时
var order = new Order();   // 一眼知道是 Order

// ❌ 不推荐：类型不明显时
var result = someMethod();  // 不知道返回什么类型
// ❌ 不推荐：链式调用太长时
var data = getService().process().getData().getValue();
// 每个方法返回什么？读起来费劲

// 阿里规范：避免用 var 造成可读性下降
```
### HTTP Client
```
// 之前 Java 用 HttpURLConnection —— 老、难用
// 第三方：Apache HttpClient、OkHttp —— 各自为政
// Java 11 终于标准化了 HTTP Client
```
基本使用
```
// ① 同步 GET
HttpClient client = HttpClient.newHttpClient();

HttpRequest request = HttpRequest.newBuilder()
    .uri(URI.create("https://api.example.com/users/1"))
    .GET()
    .build();

HttpResponse<String> response = client.send(request, HttpResponse.BodyHandlers.ofString());

System.out.println(response.statusCode());   // 200
System.out.println(response.body());          // JSON 字符串

// ② POST + JSON
HttpRequest postRequest = HttpRequest.newBuilder()
    .uri(URI.create("https://api.example.com/users"))
    .header("Content-Type", "application/json")
    .POST(HttpRequest.BodyPublishers.ofString("{\"name\":\"张三\"}"))
    .build();

// ③ 异步请求（CompletableFuture）
HttpClient asyncClient = HttpClient.newHttpClient();

CompletableFuture<HttpResponse<String>> future =
    asyncClient.sendAsync(postRequest, HttpResponse.BodyHandlers.ofString());

future.thenAccept(response -> {
    System.out.println(response.statusCode());
    System.out.println(response.body());
});

// ④ 连接池复用
HttpClient pooledClient = HttpClient.newBuilder()
    .version(HttpClient.Version.HTTP_2)   // 支持 HTTP/2
    .connectTimeout(Duration.ofSeconds(5))
    .build();
```
HTTP Client的特性

|特性|说明|
|---|---|
|**HTTP/2**|原生支持（比 1.1 快）|
|**异步**|sendAsync 返回 CompletableFuture|
|**连接池**|自动复用连接|
|**WebSocket**|原生支持|
|**响应式**|BodyHandlers 灵活处理|
对比第三方库

|对比|标准 HTTP Client|OkHttp|Apache HttpClient|
|---|---|---|---|
|**标准化**|✅ JDK 自带|第三方|第三方|
|**HTTP/2**|✅|✅|支持|
|**异步**|✅ CompletableFuture|✅|✅|
|**生态**|新，简单|成熟|老牌|
|**推荐**|简单场景|复杂场景|老项目|
